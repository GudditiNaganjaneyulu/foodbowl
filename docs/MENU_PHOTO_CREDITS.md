# Menu photo credits

The demo dishes' photos come from [Wikimedia Commons](https://commons.wikimedia.org/) under the licences below (several require attribution, hence this file). They are **not** stored in this repository or the web app: they live in the Supabase Storage bucket `menu-images` under `seed/<name>.jpg`, and the seed (`pnpm db:seed`) simply points each menu item at its bucket URL. Replace any of them from **Admin → Menu** with your own photo.

If the bucket is ever emptied, the "Photo" column links to each original so it can be re-uploaded under the same name.
